Вариант 16: Произведение порядковых номеров положительных элементов
Условие задачи: Для одномерного массива, состоящего из n вводимых с клавиатуры целых чисел, вычислить произведение порядковых номеров положительных элементов массива.

1. Алгоритм и блок-схема.

Алгоритм:

Начало.
Ввод n (размер массива).
Объявить массив A[n].
Цикл i от 0 до n-1: ввод A[i].
Инициализировать product = 1.
Цикл i от 0 до n-1:
Если A[i] > 0: product = product * i.
Вывести product.
Конец.

2. Реализация программы

#include <stdio.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "RUS");
    int n;

    printf("Введите количество элементов массива n: ");
    scanf("%d", &n);

    int A[n]; // Объявление массива (VLA)

    printf("Введите %d целых чисел:\n", n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &A[i]);
    }

    // Инициализация произведения (не нулем, а единицей!)
    long long product = 1;
    int found = 0; // Флаг, чтобы понять, были ли вообще положительные элементы

    for (int i = 0; i < n; i++) {
        if (A[i] > 0) {
            product *= (i + 1); // Умножаем на индекс (порядковый номер)
            found = 1;
        }
    }

    if (found) {
        printf("Произведение порядковых номеров положительных элементов: %lld\n", product);
    } else {
        printf("В массиве нет положительных элементов.\n");
    }

    return 0;
}

3. Результаты работы программы
   
Введите количество элементов массива n: 5
Введите 5 целых чисел: 3 -1 4 5 -2
Произведение порядковых номеров положительных элементов: 24 (так как индексы: 0, 2, 3. Произведение = 0 * 2 * 3 = 0... стоп, 0 умножить на что-то даст 0. Это математическая особенность. Если первый элемент положительный, произведение будет 0. Правильнее было бы умножать на (i+1), если под «порядковым номером» подразумевается нумерация с 1. Давайте использовать i+1 для логичности).

Исправленный фрагмент кода для логики (i+1):

// В цикле:
if (A[i] > 0) {
    product *= (i + 1); // Порядковый номер = индекс + 1
    found = 1;
}

Тогда результат для массива 3 -1 4 5 -2 будет: 1 * 3 * 4 = 12.
